# 详细模块设计

## 一、总体分层

建议采用四层结构：
- 采集层
- 聚合层
- 服务层
- 展示层

```text
[LibreHardwareMonitor / ETW / IP Helper]
                ↓
        [Collector 采集层]
                ↓
        [Aggregator 聚合层]
                ↓
      [Storage + Cache 存储层]
                ↓
      [Web API + SignalR 服务层]
                ↓
         [Vue3 Web 前端]
```

---

## 二、模块拆分

## 1. Monitor.Service

### 责任
- 程序启动入口
- 依赖注入注册
- 后台任务调度
- Windows Service 托管
- 配置中心初始化

### 建议内部组件
- `Bootstrapper`
- `CollectorHostedService`
- `AggregationHostedService`
- `CleanupHostedService`
- `AppConfigurationProvider`

---

## 2. Monitor.Hardware

### 责任
封装硬件采集逻辑，对外暴露统一硬件快照。

### 采集项
- CPU 占用率
- CPU 温度
- CPU 当前频率
- 内存总量
- 内存已用量
- 内存使用率
- 磁盘温度
- 开机时间

### 建议类设计
- `IHardwareCollector`
- `LibreHardwareCollector`
- `HardwareSnapshot`
- `CpuMetrics`
- `MemoryMetrics`
- `DiskMetrics`
- `SystemMetrics`

### 输出模型
统一输出为“单次快照”，便于前端实时展示和历史落盘。

---

## 3. Monitor.Network

### 责任
采集、识别、聚合网络事件。

### 推荐子模块

#### 3.1 EtwNetworkCollector
- 监听 ETW TCP/IP 事件
- 获取 PID、方向、大小、地址、端口、协议

#### 3.2 ProcessResolver
- PID -> 进程名
- PID -> 可执行文件路径
- 支持缓存，避免频繁查系统

#### 3.3 AddressClassifier
- 判断目标地址属于：
  - LAN
  - WAN
  - Loopback
  - Multicast / Broadcast
- WAN/LAN 规则可配置

#### 3.4 TrafficAggregator
- 按时间桶聚合
- 按 app 聚合
- 按 WAN/LAN 聚合
- 按接口聚合（可选）

#### 3.5 NetworkUsageSnapshotProvider
输出实时快照：
- 当前总上传/下载速率
- 当前各 app 上传/下载速率
- 当前 WAN / LAN 速率

### 建议类设计
- `INetworkCollector`
- `EtwNetworkCollector`
- `INetworkAggregator`
- `TrafficBucket`
- `AppTrafficUsage`
- `ProtocolType`
- `TrafficDirection`
- `AddressScopeType`

---

## 4. Monitor.Storage

### 责任
保存历史数据并提供查询能力。

### 子模块
- `DbConnectionFactory`
- `HardwareRepository`
- `NetworkTrafficRepository`
- `AggregationRepository`
- `RetentionService`

### 数据写入策略
- 实时数据先进入内存缓存
- 以固定周期批量写入 SQLite
- 避免每条网络事件直接落盘导致写放大

### 查询场景
- 最近 1 分钟硬件曲线
- 指定时间区间的 app 流量排行
- 按 1 分钟 / 5 分钟 / 1 小时聚合结果

---

### 内容

### 示例

- `HardwareRealtimeDto`

- 硬件实时快照

## 三、跨模块关键设计

## 1. 时间粒度
支持：
- 实时（1 秒）
- 10 秒
- 1 分钟
- 5 分钟
- 1 小时

## 2. 缓存策略
- 最近 5~15 分钟实时数据保留在内存
- 历史数据保留在 SQLite
- 查询先读聚合表，减少计算量

## 3. 配置化能力
可配置项建议包括：
- 监听端口
- 采样间隔
- 刷新频率
- 历史保留天数
- WAN/LAN 判断规则
- Top N 数量

## 4. 后期扩展预留
- 告警阈值
- 多主题 UI
- 进程分组
- 导出 CSV
- 多设备接入
