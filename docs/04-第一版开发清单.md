# 第一版开发清单

## 开发目标
在第一版中优先实现“能采、能存、能看”。

即：
- 后台持续采集
- 本地 HTTP 服务可访问
- Web 页面可查看实时与历史信息
- 支持按 app 查询网络流量

---

## 一、基础工程初始化

### 任务 1：创建解决方案与项目
- 创建 `.sln`
- 创建 `Monitor.Service`
- 创建 `Monitor.Hardware`
- 创建 `Monitor.Network`
- 创建 `Monitor.Storage`
- 创建 `Monitor.Contracts`
- 创建 `Monitor.WebApi`

### 任务 2：配置基础依赖
- ASP.NET Core
- SignalR
- SQLite
- LibreHardwareMonitor
- ETW 相关库
- 日志组件

### 任务 3：统一基础能力
- 配置读取
- 依赖注入
- 日志输出
- 全局异常处理

---

## 二、硬件采集 MVP

### 任务 4：封装 LibreHardwareMonitor
- 初始化 Computer 对象
- 启用 CPU / Memory / Storage 传感器
- 实现一次性采样接口

### 任务 5：标准化硬件快照
输出字段：
- CPU 使用率
- CPU 温度
- CPU 频率
- 内存总量
- 内存已用
- 内存使用率
- 磁盘温度
- 开机时长

### 任务 6：采样调度
- 每 1 秒或 2 秒采集一次
- 写入内存缓存
- 批量持久化 SQLite

---

## 三、网络采集 MVP

### 任务 7：接入 ETW 网络事件
- 启动 ETW 会话
- 监听收发事件
- 解析 PID、方向、字节数、远端地址

### 任务 8：实现进程解析
- PID -> process name
- PID -> executable path
- 构建 app registry

### 任务 9：实现 WAN/LAN 分类
- 私网地址识别
- 本地子网识别
- Loopback 识别
- 默认规则配置化

### 任务 10：实现网络聚合器
- 按时间桶聚合历史数据
- 按 app 维度聚合
- 按 WAN/LAN 维度聚合

---

## 四、数据存储 MVP

### 任务 11：创建 SQLite 数据库与建表
- `settings`
- `hardware_samples`
- `app_registry`
- `network_usage_agg`

### 任务 12：实现仓储层
- 插入硬件快照
- Upsert app registry
- 批量插入网络聚合数据
- 区间查询

### 任务 13：实现保留策略
- 定期清理过期历史
- 避免数据库无限增大

---

## 五、后端服务 MVP

### 任务 14：搭建 Web API
实现接口：
- `GET /api/overview`
- `GET /api/hardware/realtime`
- `GET /api/hardware/history`
- `GET /api/network/dashboard`
- `GET /api/network/apps`
- `GET /api/settings`
- `POST /api/settings`

### 任务 15：接入 SignalR
推送：
- 硬件实时数据

### 任务 16：本地端口配置化
- 端口写入配置
- 支持启动时加载
- 支持后续页面修改

---

## 六、前端页面 MVP

### 任务 17：搭建前端基础页面
至少包含：
- 总览页
- 网络页
- 设置页

### 任务 18：实现总览页
展示：
- CPU 使用率
- 内存使用率
- CPU 温度
- 磁盘温度
- CPU 频率
- 开机时长
- 当前总上传/下载速率

### 任务 19：实现网络页
展示：
- 时间区间选择
- 按 app 的上传/下载表格
- WAN/LAN 占比图
- Top N 排行

### 任务 20：实现设置页
配置项：
- HTTP 端口
- 采样间隔
- 默认时间粒度
- 历史保留天数

---

## 七、测试与验证

### 任务 21：基本联调验证
- 采集是否连续稳定
- 页面是否可实时刷新
- 历史查询是否正确
- app 聚合是否基本准确

### 任务 22：性能验证
- CPU 占用是否可接受
- 内存增长是否稳定
- SQLite 写入是否平稳

### 任务 23：异常场景验证
- 某些传感器读取失败
- 某些进程无法解析路径
- ETW 会话重启
- 前端断线重连

---

## 八、第一版完成标准

满足以下条件即可视为 V1 可用：
- Win11 上可以稳定运行
- 本地 HTTP 页面可访问
- 能显示硬件实时信息
- 能显示网络总流量
- 能按 app 查询网络使用量
- 能区分 WAN/LAN
- 能按时间区间查询历史数据

---

## 九、建议优先级

- 硬件采集

- 设置页
- 历史查询

### P2（后续优化）
- 更美观 UI
- 告警
- 导出
